# 驾车路线模拟调研

调研分支：`codex/driving-route-research`。本文件只记录现有实现、可行方案和验收点，尚未实现驾车模拟，也未进行真机验证。

## 结论

可在现有路线模拟链路上增加驾车模式，但仅放宽“步行速度”上限不能满足需求：目前路线规划明确使用 MapKit 的 `.walking`，高速移动仍会沿步行路径前进。MapKit 的路线请求支持 `.automobile`，因此应先让路线模式决定道路，再让速度决定沿路线前进的距离。

难度为中等。主要改动在路线模式、预览界面、速度模型、会话恢复和验收；底层定位通道已接受连续坐标更新，暂时没有证据要求改动配对协议。

## 现有链路

| 环节 | 当前行为 | 驾车模式需要的变化 |
| --- | --- | --- |
| 规划 | `WalkingRoutePlanner.preview` 请求 `.walking`，只取首条路线 | 支持 `.automobile`，在预览前选择模式；路线不可用时明确报错 |
| 起点 | 默认使用系统当前定位 | 长途场景需检查起点准确性；中断恢复应从最后保存位置重新规划 |
| 预览 | `WalkingRoutePreviewCard` 只有 1.0、1.4、1.8 m/s 三档 | 按模式显示速度单位、范围、预计时长及相应文案 |
| 推进 | `WalkingSimulationController` 每秒用“速度 × 实际经过秒数”累计路程，再沿折线插值 | 数值计算可复用；高速度时检查跳动、弯道和到达行为 |
| 注入 | Swift 提交新坐标；Rust 原生循环每 200 ms 检查坐标变化，另有 4 秒保活刷新 | 先真机测量坐标发送及其他 App 的实际定位观感，再决定是否调整频率 |
| 恢复 | 记录步行速度，但恢复时只接受三个枚举值并重新请求步行路线 | 持久化路线模式和实际速度数值；兼容旧的 `walkingRoute` 记录 |
| 后台 | 通过 Core Location 更新维持原生会话；Swift 路线推进依赖任务继续执行 | 长途锁屏、切后台、网络变化与重连必须真机验收 |

## 建议的首版范围

1. 在预览前选择“步行 / 驾车”，分别请求对应的 MapKit 路线；沿用一条首选路线，暂不加入途经点、备选路线或交通预测。
2. 保留步行三档；驾车提供常用速度及有界的自定义值，显示 km/h。速度表示模拟位置沿路线推进的恒定速度，不代表道路限速或实时路况。
3. 预估时间统一按模拟路线长度 ÷ 所选速度计算，并明确区别于 Apple 地图的预计交通时间。暂停时不要显示不断后移的“预计到达时刻”。
4. 将路线类型和速度一起写入恢复记录。旧记录按步行解码，避免升级后丢失已有中断会话。
5. 将步行专属的按钮、地图标记、恢复提示和说明文案按模式呈现；保留“停止并恢复真实位置”的既有操作。

## 主要风险与需要实测的项目

- **路线是否可用**：跨城、偏远地点、跨水域等线路的 MapKit 返回结果及错误，需要用具体路线测试；代码静态检查无法证明覆盖范围。
- **路线起终点**：现有起点取路线折线首点，可能与设备真实坐标存在偏差；应检查开始时是否突跳。恢复时从最后注入位置重新规划，也可能产生新的短距离跳动。
- **高速观感**：100 km/h 约为 27.8 m/s；每秒更新一次时，观察位置的 App 可能看到约 28 米的离散移动。折线插值保证点落在路线折线上，但不会自动模拟加速、减速、转弯或拥堵。
- **长路线性能**：现有 `coordinate(at:)` 每次线性扫描累计距离数组；在长路线、高点数下，应测量耗时，必要时改二分查找。
- **长时运行**：验证前台、锁屏、切后台、暂停恢复、来电/系统中断、断网后恢复，以及停止后真实位置是否恢复。现有后台保活不等于已验证连续数小时的路线推进。
- **导航类 App 的表现**：只模拟坐标，没有真实车辆速度、航向、运动传感器或路况信号；不同 App 对模拟位置的处理可能不同，不能承诺等同真实驾车。

## 建议的实现顺序

先做一条短途驾车路线的本地原型，证明 `.automobile` 路线、速度推进和到达行为；再补完整的模式化 UI 与恢复记录；最后选城区、高速、跨城三类路线做真机验收。通过这些验证后再决定是否需要更高的更新频率、动态速度或途经点。

参考：Apple Developer Documentation 的 [`MKDirections.Request.transportType`](https://developer.apple.com/documentation/mapkit/mkdirections/request/transporttype)、[`MKDirectionsTransportType.automobile`](https://developer.apple.com/documentation/mapkit/mkdirectionstransporttype/automobile) 和 [`MKRoute.expectedTravelTime`](https://developer.apple.com/documentation/mapkit/mkroute/expectedtraveltime)。
